# Module 5 — Courses

**Who manages this:** Admin and Chair

---

## What It Is

Courses are the individual subjects taught under a program. Each course holds its academic details and is mapped to Program Outcomes to show which outcomes it covers — and to what level.

> A course must have at least one Program Outcome mapped before a syllabus can be created for it.

---

## Where to Find It

1. Go to **Courses** from the sidebar
2. Select your program using the program selector

Courses are displayed grouped by Year Level, then Semester.

---

## How to Add a Course

1. Click **Add Course**
2. Fill in the course details:

### Basic Information

| Field | Details |
|---|---|
| Course Code | Short identifier (e.g., AGRI 101) — must be unique |
| Course Title | Full name of the course |
| Course Description | Brief overview (optional) |
| Credit Units | Number of units — required |
| Has Laboratory | Select **Yes** or **No** |
| Year Level | Select 1 through 5 |
| Semester | Select 1st or 2nd Semester |
| Passing Mark | Choose from: 50%, 55%, 60%, 65%, 70%, 75%, 80% (default: 60%) |
| LEC Class Hours | Choose from: 1 hr, 1 hr 30 min, 2 hr, 2 hr 30 min, 3 hr |
| LAB Class Hours | Same options — only visible when Has Laboratory is Yes |
| Prerequisite | Text field — write "None" if not applicable |
| Corequisite | Text field — write "None" if not applicable |

> The **Has Laboratory** option is locked and cannot be changed if the course already has an existing syllabus. You must delete all syllabi linked to the course before you can change this.

### Program Outcome Mapping

3. Scroll to the **Program Outcomes Mapping** section
4. For each Program Outcome listed, select the level that applies to this course:

| Level | Meaning |
|---|---|
| **I** — Introductory | Students are first introduced to this outcome in this course |
| **E** — Enabling | Students practice and develop this outcome in this course |
| **D** — Demonstrating | Students demonstrate full mastery of this outcome in this course |
| *(blank)* | This outcome is not covered in this course |

5. Click **Reset IED Levels** if you want to clear all selections and start over
6. Click **Create Course**
7. A confirmation modal appears showing a summary — review and click **Confirm** to save

---

## How to Edit a Course

1. Click the **Edit button** on the course row
2. Update any fields or mappings
3. Click **Update Course**
4. A confirmation modal appears — click **Confirm** to apply changes

---

## How to View Course Details

Click the **View button** (eye icon) on any course row to open a popup with the full course details.

---

## How to Archive a Course

Archiving hides a course from the active list without deleting it. Use this for courses no longer being offered.

1. Click the **Archive button** on the course row
2. Confirm the action

To see archived courses, click the **Archived** tab above the course list. Archived courses show a **Restore** button.

---

## How to Restore an Archived Course

1. Click the **Archived** tab
2. Click **Restore** on the course you want to bring back

---

## How to Delete a Course

> Deleting a course permanently removes it and all syllabi linked to it.

1. Click the **Delete button** on the course row
2. Confirm the deletion in the dialog

Only admins and the assigned department chair can delete courses.

---

## Notes

- If no Program Outcomes are defined for the program yet, the mapping section will show an empty state. Go to the Programs module and add POs first.
- Admins can manage courses for any program
- Chairs can only manage courses for programs in their assigned department

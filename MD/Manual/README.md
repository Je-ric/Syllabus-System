## Recommended Setup Order

Before any faculty member can create a syllabus, the following must be set up in order:

1. Admin/Dean adds College Goals
2. Admin/Chair adds Department Objectives
3. Admin/Chair adds PEOs for the program
4. Admin/Chair adds POs and maps them to PEOs
5. Admin/Chair adds Courses and maps each course to POs with IED levels
6. Faculty creates Syllabi — only possible after step 5 is done for a course

# College Goals and Department Objectives Rules

This document summarizes conditions for managing goals and objectives.

## Source Controllers

- `app/Http/Controllers/GoalController.php`
- `app/Http/Controllers/ObjectiveController.php`

## College Goals

### Listing Behavior

- Colleges are loaded in name order.
- Selected college comes from query `college_id`.
- If no query selection, defaults to user's primary college assignment when available.

### Create Conditions

- `college_id` is required and must exist.
- `goal_text` is required string.

### Create Behavior

- `college_goals_code` is auto-generated by model helper:
- `College::getNextGoalCode()`

### Update Conditions

- `goal_text` is required string.

### Delete Behavior

- Goal is deleted.
- Remaining goal codes are resequenced using:
- `College::resequenceGoalCodes()`

## Department Objectives

### Listing Behavior

- Selected college/department come from query params when provided.
- If missing, defaults from user's primary department assignment.
- Departments shown are restricted to selected college.
- Objectives shown are restricted to selected department.

### Create Conditions

- `college_id` is required and must exist.
- `department_id` is required.
- `department_id` must belong to selected `college_id`.
- `objective_text` is required string.

### Create Behavior

- `dept_obj_code` is auto-generated by:
- `Department::getNextObjectiveCode()`

### Update Conditions

- `objective_text` is required string.

### Delete Behavior

- Objective is deleted.
- Remaining department objective codes are resequenced using:
- `Department::resequenceObjectiveCodes()`
